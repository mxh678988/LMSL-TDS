一句话定位

TDS（Taiji Dispatch Scheduler）是宿主无关的显存调度 SDK：以太极理论逻辑（阴阳分层、三才存储、四象压力、八卦域分类）做全域淘汰序推演与动态显存预算，实现按需加载与预取，在有限显存下最大化可用上下文与推理性能，且无宿主硬依赖。

分层架构

任务/对话输入
   ↓
[语义感知层] 八域分类 -> 任务画像          (core/classifier.py)
   ↓
[调度决策层] 冷热权衡 / 预取 / 淘汰 / 压力保护 (core/planner.py, scheduler.py, memory.py)
   ↓
[执行接入层] 框架 Hook（ComfyUI / llama.cpp / Mobile）  (adapters/*)
   ↓
存储层级：GPU 显存 -> CPU 内存 -> 本地 SSD   (core/storage.py)

四象压力策略：LOW / CRITICAL / HIGH / FROZEN 四档压力水位，高压力下仅放行释放类动作（下沉/淘汰），OOM 防护与崩溃回退内置。
