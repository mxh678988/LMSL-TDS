快速安装

# 安装 SDK（宿主无关内核，零第三方运行时依赖）
pip install tds-core

当前 PyPI 上架版本：tds-core 0.3.0（冻结基线，含自有签名安全模块）。

宿主无关契约

TDS 适配层只依赖 5 个契约方法，接 ComfyUI、A1111、Fooocus 或自研后端同等成本：

方法职责
load将模型/权重加载进显存
unload从显存卸载/下沉模型
prefetch预取即将使用的模型/页
vram_state上报当前显存占用状态
io_cost估算加载/卸载的 IO 开销

接入示例

from tds.api import TDSRuntime
from tds.adapters import YourAdapter  # 实现 BaseAdapter 契约即可

rt = TDSRuntime(config=cfg)
rt.register_adapter(YourAdapter(...), "your-host")
rt.attach("your-host")
# 每次推理决策前: rt.run_task(...) -> {step, primary, scores, pressure, action, plan, applied}
注：tds.adapters 为随宿主部署的可选配件，不随 tds-core SDK 包分发；上例仅示意宿主侧契约，实际由集成方按 BaseAdapter 契约自实现。

发布包完整性三重校验

  1. SHA256 完整性：对照发布包 CHECKSUMS.txt
  2. Ed25519 验签：用随包公钥验证 wheel 的 detached 签名（签名即授权）
  3. 公钥指纹绑定：核对公钥指纹，防公钥整体替换（首次信任后固化）
# 校验发布包自有签名
python -m tds.security.verify <wheel文件> <wheel.sig文件>

# 作为模块调用
from tds.security import verify_wheel
result = verify_wheel("tds_core-0.3.0-py3-none-any.whl", "tds_core-0.3.0-py3-none-any.whl.sig")
assert result["ok"]

三层架构与存储层级

[语义感知层] 八域分类 -> 任务画像          (core/classifier.py)
[调度决策层] 冷热权衡 / 预取 / 淘汰 / 压力保护 (core/planner.py, scheduler.py, memory.py)
[执行接入层] 框架 Hook（ComfyUI / llama.cpp / Mobile）  (adapters/*)
存储层级：GPU 显存 -> CPU 内存 -> 本地 SSD   (core/storage.py)
  • 八域语义分类：乾坤 / 对话 / 检索 / 代码 / 图像 / 视频 / 工具 / 其他
  • 阴阳冷热分层：阳=热数据驻留显存；阴=冷数据下沉内存/SSD
  • 四象压力策略：LOW / CRITICAL / HIGH / FROZEN，高压力仅放行释放类动作
  • 预判预取：统计热度 + 启发式预取（Belady 近似）
